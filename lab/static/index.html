A SMALL INTERVENTION, A LARGE SHIFT


Change the signal.
Watch the story change.


We keep the trained model’s weights unchanged and temporarily adjust numbers inside its computation. The same question can then produce a different voice, theme or self-description. This is called activation steering.


The simple idea: change an internal signal while the model writes, then compare its answer with the same model answering without that change. A recipe is a set of instructions for this intervention—not a separately trained character.





1. What signal are we changing?


The model reads and writes tokens: pieces of text, which can be words, parts of words or punctuation. For each token, it passes numbers through a sequence of layers, or processing stages. Each layer updates a shared working representation called the residual stream.


That representation is a vector: an ordered list of numbers with thousands of coordinates. These numbers help later layers decide which token to write next. They are not readable sentences, and a coordinate does not have one guaranteed human meaning.


A layer’s feed-forward block, also called its MLP, computes many neuron activations. A neuron here is a numerical processing unit, not a biological brain cell. An activation is a temporary number calculated for the current input; a weight is a learned parameter stored in the model. We adjust selected activations before their contributions are added back to the residual stream.







2. Read the equation one piece at a time


For one neuron using normalized additive steering, the extra contribution is:


h ← h + dose × rL × Wdown[:, n] / ‖Wdown[:, n]‖2


In words: take a learned direction, give it a chosen strength, and add it to the model’s working vector.


Equation glossary
Symbol or termWhat it means


hThe residual-stream vector being updated: the model’s shared working numbers at this point in layer L.


←“Replace with.” The expression on the right becomes the new value of h.


+Add the extra vector coordinate by coordinate to the existing vector. We do not replace the model’s whole representation.


doseThe signed strength you choose. A positive value pushes along the direction; a negative value pushes against it. Zero adds nothing for this component. Negative does not mean “bad,” and reversing the sign does not guarantee an opposite personality.


×Multiply. Multiplying a vector by a single number scales every coordinate, changing the strength of the nudge.


LThe layer index: which processing stage receives the intervention. Layer and neuron indexes in this lab start at zero.


rLA reference size for the unsteered residual stream at layer L. We measure vector lengths over reference tokens and take their median—the middle measured length. This is a number, not a direction.


WdownThe layer’s learned down-projection matrix: a table of weights that maps the MLP’s many neuron activations back into the residual stream’s coordinates.


nThe neuron index inside that layer’s MLP. It is an address within this particular model, not a universal ID for a concept such as “poet.”


[:, n]“All rows, column n.” This selects the output-weight column belonging to neuron n. That column is the direction in which this neuron contributes to the residual stream.


‖…‖2The Euclidean length, or L2 norm, of the selected column. Square its coordinates, add those squares, then take the square root. For the vector (3, 4), the length is √(3² + 4²) = 5.


/ ‖…‖2Divide the column by its length to make a unit-length direction. Multiplying it by dose × rL then sets the size of the added vector.




The lab implements this with a temporary hook just before the down projection. Because that projection is linear, changing one input activation adds the corresponding scaled weight column to its output. The equation describes that extra residual contribution. Raw addition instead adds a number directly to the neuron activation, without this reference scaling. Multiplication scales the existing activation: factor 1 leaves it unchanged and factor 0 zeros it. Those modes do not follow this normalized additive equation.







3. A small numerical example


Imagine a toy model with only two coordinates, instead of thousands. Suppose the reference length rL is 10, and the chosen neuron’s output column is (3, 4).


    

  1. Its length is 5, so its unit direction is (3, 4) / 5 = (0.6, 0.8).
    2. 

  2. Choose dose +0.2. The extra vector is 0.2 × 10 × (0.6, 0.8) = (1.2, 1.6).
    3. 

  3. If the working vector was (8, 6), it becomes (9.2, 7.6).
    4. 



The added vector has length 2: 20% of the reference length. This does not mean 20% more humor, a 20% probability of a persona, or a 20% increase in the final vector’s length. The result depends on its direction and on everything the model computes afterward.


For a single component in this mode, dose magnitude 1 adds a vector as long as the reference residual vector. Editing only one neuron can therefore be a strong intervention. Two added directions may reinforce or partly cancel each other; their behavioral effects need not add neatly.







4. Why can this change a whole story?


Training has already taught the model patterns associated with roles, subjects, emotions and styles of writing. Those patterns are distributed across interacting features. Steering can make some patterns more influential in the computation; it does not insert a ready-made character or teach a new skill by itself.


Later layers transform the changed representation into scores for possible next tokens. If a recipe keeps applying the nudge, the influence can recur at many steps. The words already generated also become part of the next step’s context, which can reinforce the same theme.


That feedback helps explain both the striking successes and the failures: a cookie reference can grow into a cookie-themed explanation, while an excessive or poorly chosen nudge can produce repetition, unrelated associations or false facts. A coherent voice is a different measurement from factual accuracy.


The recipe also specifies when to intervene: while reading the prompt, while generating, or both. Directions at the same layer add as vectors; interventions at different layers pass through further computations and can interact in less predictable ways.







5. Why the normalization source matters


Normalization gives the dose a reference scale. Neuronary recipes use fixed calibration text or a published reference table. Persona Library recipes use the unsteered prompt’s residual norms, so the scale can change with the prompt. Our measurements exclude the first token when computing these medians.


The same dose number can therefore mean different absolute changes under different normalization methods. Equal doses also do not promise equal behavior across neurons, prompts or models. The lab preserves a recipe’s declared method; inspect its source before comparing results.







6. How can new personas be found?


There is no reliable dictionary that translates a neuron number into a personality. Discovery is an experiment: find a candidate intervention, observe the difference, and test whether the pattern holds up.


    

  1. Define an observable target. For example, a poetic explanation of ordinary questions. Use the same neutral prompts for baseline and steered runs; explicitly asking only the steered model to “be a poet” would mix prompting with neuron steering.
    2. 

  2. Choose candidates for the exact model. Start from published recipes, measured activation patterns, or a systematic screen of neuron-and-dose pairs. Layer and neuron indexes are not interchangeable between models.
    3. 

  3. Change one thing first. Try a range of signed doses on one candidate, keeping the prompt, model revision and decoding settings fixed. Compare the actual outputs with the unsteered baseline.
    4. 

  4. Test beyond the first funny answer. Use unrelated questions, paraphrases, repeated runs and longer outputs. Check personality, coherence, repetition and factual accuracy separately. With our greedy decoding, changing only the seed usually produces the same answer; that is not a test of broad robustness.
    5. 

  5. Combine cautiously. After testing components individually, try combinations and retest them. Removing a component or lowering a dose may help more than adding another. A larger recipe is not automatically a better one.
    6. 

  6. Save the evidence with the recipe. Keep the model revision, neuron indexes, signed doses, normalization, application scope, prompts, output limits and full responses. Give it a descriptive label only after observing what it actually does.
    7. 



Our current persona exploration primarily starts from published recipes and tunes their doses or combinations. The registered 27B architecture alone has 64 × 17,408 = 1,114,112 MLP neuron positions; importing a searchable catalog does not mean we have tested every possible intervention.


A model can help rank candidates for humor, but that ranking is a judgment, not a measurement of everyone’s taste. Human review and further prompts help distinguish a repeatable tendency from a lucky one-off. Saved experimental presets can remain marked pending until their full validation batch is completed.





What stays unchanged? The trained weights. These hooks modify temporary activations and are removed after each generation. Weight editing and fine-tuning change model parameters; this lab’s persona switches do neither. A persona label is not evidence of consciousness, a stable identity, or a personality localized in one neuron. The 3D atlas is a visualization—not the actual high-dimensional steering vector.
